# Drop

Drop is an interactive, front-end-only demo of a prompt-driven app builder, inspired by the general workspace patterns of open-source AI builders.

## Demo scope

- Responsive workspace dashboard with recent projects and starter templates
- Prompt-to-project flow with simulated build status and demo assistant responses
- IDE-style workspace with a file tree, code view, browser-style preview, and chat panel
- Local browser persistence for demo projects
- Project rename, add-file, history notice, and JSON export
- No API keys, model calls, authentication, billing, or real deployment integration

## Run locally

This is a static HTML application. Open `index.html` in a browser or serve the repository with any static web server. No build step or package installation is required.

## Important

Drop is a demo, not a production AI coding service. The AI and publishing experiences are simulated. Project data stays in the current browser unless the user exports it. Do not enter secrets or sensitive data.
